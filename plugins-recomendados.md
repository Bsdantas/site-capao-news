# Plugins recomendados para o Capão News

Esta é a lista ideal para deixar o site funcional, rápido, seguro e melhor posicionado no Google.

## 1. SEO

### Rank Math SEO

Motivo: é o melhor custo-benefício para site de notícia e blog.

Funções:
- otimização de títulos e descrições
- sitemap
- SEO para páginas e posts
- revisão de SEO por página
- schema básico
- integração com Google Search Console

Recomendação:
- instalar este plugin
- não instalar o Yoast junto, para evitar conflitos

---

## 2. Cache e performance

### LiteSpeed Cache

Motivo: melhora a velocidade do site e é muito útil para WordPress.

Funções:
- cache do site
- otimização de carregamento
- melhora no tempo de resposta
- melhor experiência mobile

Recomendação:
- instalar e ativar
- configurar cache básico

---

## 3. Compressão de imagens

### Smush

Motivo: reduz o peso das imagens sem perder muita qualidade.

Funções:
- comprime imagens
- melhora a performance
- reduz tempo de carregamento

Recomendação:
- instalar e ativar
- otimizar imagens já enviadas

---

## 4. Segurança

### Wordfence Security

Motivo: protege o site contra ataques e acessos suspeitos.

Funções:
- firewall
- scan de malware
- bloqueio de IPs maliciosos
- alertas de segurança

Recomendação:
- instalar e ativar
- deixar o firewall habilitado

---

## 5. Vídeos e embeds

### YouTube Embed Plus

Motivo: facilita muito a inserção de vídeos de YouTube nos posts.

Funções:
- embed fácil de vídeos
- melhora apresentação em artigos
- útil para reportagens e coberturas

Recomendação:
- instalar se o site quiser inserir vídeos de notícias

---

## 6. Formulários e contato

### WPForms

Motivo: útil para contato, parceria, envio de material, denúncia ou sugestão.

Funções:
- formulário de contato
- formulário de parceria
- lead capture

Recomendação:
- instalar se o site quiser receber mensagens de leitores ou anunciantes

---

## 7. Backup

### UpdraftPlus

Motivo: backup do site para caso aconteça algum problema.

Funções:
- backup completo
- restauração fácil
- armazenamento em nuvem

Recomendação:
- instalar e configurar backup semanal

---

## Lista mínima recomendada

Se quiser manter o site enxuto, instale estes 5 primeiro:

1. Rank Math SEO
2. LiteSpeed Cache
3. Smush
4. Wordfence Security
5. UpdraftPlus

Essa é a lista mais equilibrada para um site de notícia.

## Checklist rápido para o cliente

### 1) Rank Math SEO
- Ative o plugin
- siga o assistente inicial
- habilite o sitemap
- configure a descrição da home
- ajuste o SEO de cada notícia

### 2) LiteSpeed Cache
- ative o cache
- habilite otimização básica
- limpe o cache após mudanças visuais

### 3) Smush
- ative compressão automática
- otimize as imagens já enviadas

### 4) Wordfence Security
- ative o firewall
- faça o scan inicial
- deixe proteção de login ativada

### 5) UpdraftPlus
- configure backup automático
- escolha frequência semanal ou diária
- faça um backup manual inicial

### 6) CPT UI
- crie o tipo "Anúncio"
- crie o tipo "Parceiro"
- salve os tipos

### 7) ACF
- crie os grupos "Anúncio" e "Parceiro"
- adicione campos como imagem, link e status
- defina a regra para cada post type

### 8) YouTube Embed Plus
- use o bloco do plugin em matérias com vídeo
- cole a URL do YouTube

### 9) WPForms
- crie um formulário de contato
- configure e-mail de destino
- publique em uma página ou no rodapé

---

## Como cada plugin ajuda o site

### Rank Math SEO
Ajuda o site a aparecer melhor no Google, otimiza títulos e descrições e gera sitemap.

### LiteSpeed Cache
Melhora a performance e reduz o tempo de carregamento do site.

### Smush
Reduz o peso das imagens sem prejudicar muito a qualidade visual.

### Wordfence Security
Protege o site contra ataques, bloqueio de acessos suspeitos e verificações de malware.

### UpdraftPlus
Cria backups para que o site possa ser restaurado se algo der errado.

### CPT UI
Cria conteúdos extras para anúncios e parceiros dentro do painel do WordPress.

### ACF
Adiciona campos personalizados para cada item de anúncio e parceiro.

### YouTube Embed Plus
Permite inserir vídeos em matérias de forma simples e elegante.

### WPForms
Permite receber mensagens de contato, parceria e relacionamento com leitores.
